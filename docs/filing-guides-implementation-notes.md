# 신고·신청 가이드 도입

검토일: 2026-11-17 (Asia/Seoul).

## 범위와 검색 의도

신고·신청 절차를 찾는 독자를 위한 허브와 첫 가이드 5개를 추가했다. 기존 계산기는 금액·자격 확인, 새 가이드는 자료 준비·제출·완료 확인을 담당한다. 우선순위는 기존 도구와의 연계성, 절차의 독립성과 실용성을 기준으로 선정했으며 검색량·경쟁도 실측 순위가 아니다. 일반 세법 설명을 복제하지 않았다.

`calculator-registry.json`의 `guideCategories`가 가이드 인벤토리를 관리한다. `filing-guides.html`은 `hubs`에도 등록했다. 페이지별 본문은 ERB, SEO·breadcrumbs는 page-metadata, sitemap·RSS는 site-discovery가 관리한다. 기존 계산기 5개와 양방향 링크를 연결했다. 전체 공통 메뉴에 새 허브를 추가했으며 모바일 6개 메뉴를 짝수 행으로 배치한다. 계산 수식·입력·컨트롤러는 변경하지 않았다.

## 기존 시한성 데이터 점검

작업 전에 data-update-policy의 전체 목록과 같은 날의 공식 원천 점검 이력을 검토했다. 이번에는 국민연금 공식 게시목록에서 2026-07 자료 공개를 다시 확인했으나, 기존 금액별/지역별 순위 원표 전체의 새 수치를 검증하거나 갱신하지 않았다. 금융감독원·부동산원 공개 검색에서는 저장본을 대체할 정확한 새 원표를 확보하지 못했다. 같은 날 기존 감사 기록의 나머지 통계는 새 갱신을 확정할 근거가 추가되지 않았다. 최신성이 모두 확인됐다는 뜻은 아니다. 관련 없는 통계·공시 데이터와 기준일은 보존했다. 별도 데이터 갱신은 원표 대조·구체적 변경안 승인 후 수행한다.

## 간격 보완 — 2026-11-17

사용자 검수에서 문단·체크리스트 사이와 목록 뒤 문단의 간격 부족, 출처 박스 첫 목록의 불필요한 상단 여백을 확인했다. 가이드 5개와 허브에 `.filing-guide` 범위를 적용하고 박스 내부의 기본 간격을 1rem, 체크 항목 사이는 0.5rem, 단계 제목 앞은 1.5rem, 제목 뒤 설명은 0.5rem으로 통일했다. 첫 요소의 기본 margin을 제거해 박스 padding과 중복되지 않게 했다. 기존 계산기 박스에는 이 규칙을 적용하지 않는다. 같은 관례를 architecture 문서에 기록했다.

Chrome에서 해외주식 가이드의 320px 출처 목록→문단, 안내문→체크리스트와 체크 항목 사이를 시각 검수하고, 데스크톱에서 체크리스트→안내문과 단계 설명 간격을 확인했다. 6개 페이지가 같은 공통 규칙을 사용한다. 본문·SEO 필드와 계산 기능은 변경하지 않았다. `npm test`, XML 유효성 검사, `git diff --check` 모두 통과했다.

## 계산기 연결 흐름 보완 — 2026-11-17

가이드 5개 상단에서 계산 목적을 설명한 뒤 관련 계산기와 `#documents` 바로가기를 나란히 제공한다. 계산이 필요하지 않은 사람은 곧바로 가이드를 이용할 수 있다. 부모님 전용 계산기와 가족 전체를 다루는 피부양자 가이드의 범위를 구분하고, 현금 증여 가이드의 과거 증여 입력 안내를 실제 계산기의 합산 미지원 범위에 맞춰 수정했다. 가이드 끝에는 계산 재확인, 공식 기관 업무 찾기, 다른 가이드 이동을 구분했다.

기존 계산기 5개의 정적 관련 안내에 `data-result-followup`을 적용했다. 공통 결과 패널 초기화 시 해당 안내를 결과 영역의 저장·공유 버튼 뒤로 이동한다. `captureArea` 밖에 두어 명세서 내보내기에 탐색 UI가 섞이지 않는다. JS가 없으면 원래 HTML의 하단 링크를 사용할 수 있다. 계산 수식·입력 처리·결과값을 변경하지 않았다. 참고 판정으로 신청 자격이 확정됐다는 표현을 사용하지 않는다. 결과에서 돌아가는 링크는 가이드 상단 대신 준비서류 위치로 연결한다.

현재 네이버 [콘텐츠 권장사항](https://searchadvisor.naver.com/guide/content-basic)과 Google [수집 가능한 링크](https://developers.google.com/search/docs/crawling-indexing/links-crawlable?hl=ko)를 다시 확인했다. 목적이 드러나는 링크 문구, 실제 href, 정적 HTML 링크와 명확한 업무 구분을 적용했다. 계약 fixture 갱신은 본문·제목·링크가 의도적으로 바뀐 계산기 5개·가이드 5개에 한정해 검토했다. 기존 시한성 데이터 점검은 같은 날 감사 이력과 정책 목록을 재사용했으며 별도 데이터·기준일을 변경하지 않았다.

검증: 기존 선택적 DOM 검사에서 공통 계산·순위 81개 페이지를 통과했다. 관련 안내의 결과 패널 배치, 내보내기 영역 제외, 반복 초기화 시 안내·저장 버튼의 중복 방지를 추가 확인했다. 부모님 공제와 기부·추납·순위의 DOM 회귀 및 PNG/PDF/공유 모의 경로도 통과했다. 실제 Chrome에서 현금 증여 가이드 상단→계산기→예시 금액 계산→결과 아래 안내→가이드 준비서류 위치로 왕복했으며, 피부양자 가이드의 상단·하단 링크도 확인했다. 공식 기관에 실제 신청·신고는 하지 않았다. 이번 수정의 실제 모바일 기기·전체 페이지 브라우저 조작·순위·클릭률 변화는 측정하지 않았다.
