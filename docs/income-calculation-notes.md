# 종합소득세·연봉 비교 계산 기준

## 주택임대소득세 비교

- 검토일: 2026-10-01. 2025년 귀속 소득을 2026년에 신고하는 비교다. [국세청 분리과세 계산구조](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7679&mi=2247), [국세청 계산 사례](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7684&mi=2253), [지방세법 제93조](https://www.law.go.kr/법령/지방세법/제93조)를 기준으로 한다.
- 과세 대상 월세와 간주임대료 수입금액을 사용자가 확인해 입력한다. 주택 수·기준시가에 따른 과세대상 판정은 기존 간주임대료 페이지 등에서 별도 확인한다.
- 종합과세는 장부상 필요경비 차감 후 임대소득금액을 다른 종합소득 과세표준에 더한다. 기존 과세표준에 대한 국세·지방세 산출세액을 빼 임대소득으로 증가하는 금액을 표시한다. 누진세율 표는 `comprehensive-income-tax-math.js`를 재사용한다.
- 총수입 2,000만 원 이하에만 분리과세를 제공한다. 등록 우대요건을 모두 충족한 수입은 필요경비 60%, 조건부 공제 400만 원이고 미충족 수입은 50%, 200만 원이다. 공제는 주택임대 외 다른 종합소득금액이 2,000만 원 이하일 때만 적용한다. 국세 14%, 지방소득세 1.4%를 적용한다.
- 혼합 등록, 결손, 추계경비율, 소형주택 임대사업자 세액감면, 그 밖의 공제·감면, 기납부세액과 금융소득 비교과세는 제외한다. 따라서 더 낮은 산출세액을 최종 유리한 신고방식으로 단정하지 않는다.

검토일: 2026-09-28. 종합소득세 계산기는 `scripts/comprehensive-income-tax-math.js`와 `scripts/comprehensive-income-tax-calculator.js`, 연봉 순위·지역 평균 비교는 `scripts/salary-rank-table.js`, `scripts/salary-region-table.js`, `scripts/salary-rank-math.js`, `scripts/salary-rank.js`를 사용한다.

## 종합소득세 계산기

- 공식 근거: [국세청 종합소득세 세액계산 흐름도](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7666&mi=2224), [국세청 2023~2025년 귀속 종합소득세율](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7667&mi=2315), [지방세법 제92조](https://www.law.go.kr/법령/지방세법/제92조).
- 2025년 귀속 소득을 2026년에 신고하는 기본 구조다. 사업·근로·금융·연금·기타소득의 `소득금액`을 합산하고 소득공제를 차감한 과세표준에 6~45% 누진세율을 적용한다.
- 입력값은 매출, 총급여 또는 세후 실수령액이 아니다. 사업소득은 필요경비 차감 후 금액, 근로소득은 근로소득공제 후 금액, 연금·기타소득은 각 소득별 공제·필요경비 차감 후 종합과세 대상 금액을 사용한다.
- 소득공제는 종합소득금액까지만 인정하고, 입력한 국세 세액공제·감면은 산출세액까지만 반영한다. 개인지방소득세는 같은 과세표준에 0.6~4.5% 표준세율을 적용하며, 현재 계산기는 반영된 국세 공제·감면의 10%를 지방세 공제·감면 참고액으로 제한 적용한다.
- 기납부 종합소득세와 개인지방소득세는 별도로 입력하고 각 결정세액에서 차감한다. 양수는 추가 납부, 음수는 환급 예상으로 표시한다.
- 금융소득 비교과세, 배당세액공제의 상세 한도, 최저한세, 가산세, 결손금, 공동사업, 외국납부세액공제와 특별한 분리과세·감면은 지원하지 않는다. 관련 범위를 추가하려면 공식 계산 순서를 별도 모델링하고 기존 입력 하나에 임의로 합치지 않는다.

## 전국 연봉 순위

- 공식 데이터: [공공데이터포털 국세청 근로소득 백분위(천분위) 자료](https://www.data.go.kr/data/15082063/fileData.do). 현재 스냅샷은 2024년 근로소득에 대한 2025년 신고 자료이며 원본 등록일은 2026-02-24다.
- 각 분위의 총급여 합계를 인원으로 나눈 구간 평균을 사용한다. 상위 1% 이내는 0.1% 단위, 나머지는 1% 단위 자료다.
- 입력 총급여가 이웃한 두 구간 평균 사이에 있으면 평균값 사이를 선형 비교해 참고 상위 비율을 표시한다. 이는 개인별 커트라인, 실제 초과 인원 비율 또는 국세청이 공표한 개인 백분위가 아니다.
- 입력값은 비과세소득을 제외한 연간 세전 총급여다. 사업소득, 기타소득, 퇴직소득, 근로소득금액과 세후 실수령액을 합산하지 않는다.

## 지역 평균급여 비교

- 공식 데이터: [국세청 국세통계포털의 4-2-15 주소지별 표](https://tasis.nts.go.kr/websquare/websquare.html?nbsp=&w2xPath=/ui/ep/e/a/UTWEPEAA02.xml&sttPblYr=2025&sttsMtaInfrId=20250103D01202541132). 통계표 발행연도는 2025년, 현재 스냅샷의 근로소득 귀속연도는 2024년이다.
- `scripts/salary-region-table.js`에는 주소지별 **과세대상근로소득(총급여) 금액**을 해당 신고 인원으로 나눈 뒤 만원 단위로 반올림한 17개 시도 평균과 전국 평균 4,487만원을 저장한다. 원표 전국값은 21,020,286명·943,257,648백만원이며, 17개 시도 소계와 전국 합계의 차이 2,358명·36,763백만원은 지역 외/미분류분으로 보고 전국 평균에는 원표의 전국 행을 쓴다. 2026-10-01에 공식 엑셀 원표를 대조했다.
- 입력 총급여와 선택 지역 평균의 금액 차이·비율, 입력 총급여와 전국 평균의 차이, 17개 시도 평균급여 순위를 계산한다. 직장 소재지가 아니라 근로자의 연말정산 당시 주소지를 선택한다.
- 지역별 개인 소득분포가 없으므로 지역 안에서 상위 몇 퍼센트인지 추정하지 않는다. 전국 순위와 지역 평균은 모두 2024년 귀속이지만 각각 분위별 평균과 주소지별 평균이므로 한 통계처럼 합치지 않는다.

## 데이터 갱신과 검증

- 새 연도 자료로 갱신할 때 원본의 귀속연도, 신고연도, 단위, 인원 범위와 주소지·원천징수지 기준을 먼저 확인한다. 날짜만 바꾸거나 이전 값을 최신 값으로 간주하지 않는다.
- 전국 자료는 원본 합계에서 평균을 다시 계산하고 총 인원·상위 1%·10%·50% 대표값을 대조한다. 지역 자료는 17개 시도 누락, 정렬 순위, 전국 평균과 반올림 단위를 검증한다.
- `tests/calculation-regression.test.js`에서 종합소득세율 경계, 공제 상한, 납부·환급, 음수 입력, 전국 연봉 보간, 지역 선택·평균 차이와 잘못된 지역을 검증한다.
- 두 페이지는 공통 결과 패널과 PNG·PDF·공유 기능을 사용한다. 귀속연도, 통계 기준, 제외 범위와 추정 한계를 페이지 본문과 결과 안내에 함께 표시한다.
