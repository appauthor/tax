# 저경쟁 세금 계산기·순위 계산 기준

검토일: 2026-09-21. 계산은 `scripts/niche-market-math.js`, 공개 통계 스냅샷은 `scripts/niche-market-data.js`, 폼과 결과 표시는 `scripts/niche-market-calculators.js`를 사용한다.

## 가족 간 저가양수·고가양도

- 공식 근거: [상속세 및 증여세법 제35조](https://www.law.go.kr/법령/상속세및증여세법/제35조), [국세청 상속세 및 증여세 집행기준 35-26-1](https://taxlaw.nts.go.kr/downloadPDFFile.do?fleId=300000000000991467&fleSn=896290), [증여세 세액계산 흐름도](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7728&mi=2340).
- 특수관계인 저가양수·고가양도는 경제적 이익이 `min(시가 × 30%, 3억원)`을 초과할 때 그 초과액을 증여재산가액으로 계산한다.
- 특수관계가 없는 거래는 거래 관행상 정당한 사유가 없다는 사용자 확인과 시가 30% 초과를 요구하고, 증여재산가액은 경제적 이익에서 3억원을 차감한다.
- 같은 증여자의 10년 이내 종전 증여재산가액을 합산하고 관계별 공제와 사용자가 확인한 기납부 증여세를 반영한다. 세대생략 할증, 신고세액공제, 감정평가수수료, 가산세, 연부연납, 양도자의 부당행위계산과 취득세는 제외한다.
- 세법상 시가는 사용자가 확인해 입력한다. 공시가격이나 호가를 시가로 자동 대체하지 않는다.

## 상가 권리금

- 공식 근거: [국세청 기타소득 범위](https://ems.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7890&mi=6454), [필요경비·원천징수·과세최저한](https://d.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7893&mi=6457), [부가가치세 개요](https://nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7693&mi=2401).
- 영업권·점포임차권 양도대가가 기타소득이고 양수자가 원천징수의무자라는 사용자 확인을 요구한다. 시설·비품·재고 대금은 입력 범위에서 제외한다.
- 필요경비는 공급가액의 60%와 사용자가 증빙으로 확인한 실제 경비 중 큰 금액이다. 기타소득금액이 건별 5만원 이하이면 원천징수 0원, 초과하면 소득세 20%와 그 소득세의 10%인 지방소득세를 계산한다.
- 부가세 과세 여부와 포함·별도를 선택한다. 포괄양수도 여부를 자동 판단하지 않으며 양도자 입금액은 부가세 신고 전 현금흐름이다. 최종 종합소득세는 제외한다.

## 국민연금 수령액 순위

- [국민연금공단 금액별 급여수급자 현황](https://www.nps.or.kr/pnsinfo/statistics/getOHAF0116M0.do)의 2026년 3월 노령연금 6개 금액 구간과 [지역별 급여지급 통계](https://www.nps.or.kr/pnsinfo/statistics/getOHAF0119M0.do)의 2026년 4월 시도 평균을 고정 스냅샷으로 사용한다.
- 금액 구간별 수급자 수만 공개되므로 같은 구간 안을 보간하지 않는다. 결과는 더 높은 구간의 누적 비율부터 현재 구간까지 포함한 누적 비율 사이의 상위 범위다.
- 장애연금·유족연금·기초연금·퇴직연금·개인연금·일시금은 금액 순위에서 제외한다. 지역 평균 통계는 금액 구간 통계와 집계 범위가 다를 수 있음을 표시한다.

## 지역가입자 건강보험료 지역 순위

- [국민건강보험공단 2023년 지역별 의료이용 통계연보 보도자료](https://kiri.or.kr/PDF/weeklytrend/20241223/trend20241223_1.pdf)의 2023년 12월 말 시도별 지역가입자 세대당 평균 보험료를 사용한다.
- 전국 평균 92,144원은 원 단위 공식값이다. 17개 시도 값은 발표 그래프에 표시된 천원 단위 값을 보관하므로 화면에서도 `약`으로 표시한다.
- 직장가입자, 사용자 부담분과 장기요양보험료는 제외한다. 입력 보험료는 시도 평균 사이의 참고 위치만 계산하며 개인 가입자 백분위로 표현하지 않는다.
