# XIRR·현금흐름 기반 투자수익률

계산식·콘텐츠 검토일: 2026-10-29. `xirr-calculator.html`은 `savingInvestmentCalculators`의 하나의 검색 의도 페이지다. 공개 금리·세율·시세 스냅샷 없이 사용자가 입력한 날짜·현금흐름만 계산한다. 같은 날 수행한 순위 데이터 점검은 `data-update-policy.md`의 2026-10-29 기록을 따른다. 이 페이지 추가로 별도 통계값을 갱신하지 않는다.

## 공식 근거와 계산

- [Microsoft XIRR](https://support.microsoft.com/ko-kr/excel/functions/xirr-function), [XNPV](https://support.microsoft.com/ko-kr/excel/functions/xnpv-function): 실제 경과일수 / 365 지수로 할인한 현금흐름 합계가 0이 되는 연율. 윤년도 분모 365, 달력 날짜는 UTC 정수 일수로 계산한다.
- 공식 예제 `2008-01-01 -10000; 2008-03-01 2750; 2008-10-30 4250; 2009-02-15 3250; 2009-04-01 2750`: XIRR 약 37.3362535%, 할인율 9% XNPV 약 2,086.647602. 예제는 통계나 현행 금리 가정이 아니다.
- 투자·납입은 음수, 회수·인출은 양수. 별도의 잔여 평가금액은 평가일의 가상 양수 현금흐름이며 실제 회수금과 별도 집계한다. 평가일 이전의 입출금만 허용한다. 중복 입력 확인을 요구한다.
- 날짜 정렬 후 같은 날 금액을 센트 단위 정수로 합산하고 0인 순액을 제거한 뒤 부호 변화를 센다. 총 투자금·실제 회수금은 합산 전 총액을 보존한다. 1년 미만 연환산은 결과에 별도 안내한다.
- 계좌 전체 성과는 외부 자금 이동만 입력한다. 내부 매매·재투자 배당과 계좌 평가금액을 함께 중복 집계하지 않는다. 개별 자산 성과는 그 자산의 매수·매도·외부 수령 배당으로 범위를 맞춘다. 환율·세율·비용은 자동 적용하지 않는다.

## 수치해와 한계

- 독립 수학 모듈 `scripts/xirr-math.js`가 입력 검증·붙여넣기 파싱·XIRR·XNPV를 소유한다. 날짜가 다른 현금흐름의 비선형 수치해는 기존 가격 차이·복리 계산과 구조가 달라 별도 모듈을 사용한다. DOM은 `scripts/xirr-calculator.js`에 둔다.
- 연율 `r`을 `log(1+r)` 좌표로 탐색하며 지수 스케일링과 보정 합산으로 overflow와 상쇄 오차를 줄인다. 날짜별 순액 부호 변화가 한 번인 경우의 유일한 근만 확정 XIRR로 표시한다. 이분법 상대 잔차 또는 구간 폭 허용오차는 1e-13이다.
- 부호 변화가 여러 번이면 4,097개 격자와 0%를 검사해 후보를 찾는다. 로그 연율 간격 1e-6 미만 후보는 병합한다. 모든 근·접점 근·매우 가까운 근의 검출은 보장하지 않는다. 하나만 찾아도 유일한 XIRR로 표시하지 않는다. 365일 간격 `-100,+230,-132`는 10%·20% 두 근, `-100,+200,-100`은 0% 접점 근을 검증한다.
- 연율 탐색은 −99.9999%~100,000,000%, XNPV 목표 연율은 −99%~1,000%. 해 없음·범위 밖·동일 날짜·모든 순액 상쇄를 구분한다. 실패를 0% 또는 −100%로 대체하지 않는다.
- 최대 200행(별도 평가액 제외), 1900~2199년 유효 날짜, 36,525일 기간, 각 금액 절댓값 1조·총 절댓값 합계 10조, 소수 둘째 자리까지 지원한다. 브라우저 저장·금융 입력 전송은 구현하지 않는다.

## 검증

- 오류 안내는 평소 `hidden`으로 숨기고 오류가 발생했을 때만 표시한다. 입력 수정·초기화·성공 계산 시 다시 숨긴다. `.notice-text`의 `inline-flex`가 `hidden` 표시를 덮어쓰지 않도록 공통 `[hidden]` 스타일과 DOM 검증을 유지한다.

- `npm test`는 `tests/xirr.test.js`를 포함하며 공식 예제·음수/0/큰 수익률·윤년·같은 날 합산·평가액·복수근·접점 근·입력 범위와 붙여넣기 오류를 검증한다.
- `node tests/xirr-dom.test.js /tmp/taxyou-xirr-qa/node_modules/jsdom`은 임시 jsdom을 사용해 행 추가·삭제, 붙여넣기 원자성, 평가액 토글, 오류와 오래된 결과 숨김, PNG/PDF/공유 호출을 검증한다. jsdom은 사이트 의존성에 추가하지 않는다.
- Chrome에서 데스크톱·400px 반응형 화면과 실제 PNG 저장본을 확인했다. 접힌 내역 표가 캡처에 일부 섞이는 현상을 방지하기 위해 상세 내역은 `captureArea` 밖에 두고 리포트에는 합계·기간·건수만 넣는다. XIRR 리포트만 `data-pdf-compression="FAST"`를 설정해 jsPDF의 PNG 무손실 압축을 사용한다. 공통 PDF 기본값은 기존대로 유지하며 DOM 테스트에서 두 분기를 검증한다.
- SEO와 공개 계약 fixture는 새 URL·홈 목록·관련 링크·메타데이터·FAQ·사이트맵·RSS 변경을 검토한 뒤 갱신한다.
