# 부모님 인적공제 계산기

검토일: 2026-11-12 (한국시간). 적용: **2026년 귀속 / 2027년 초 연말정산**. 2027년 귀속이나 미확정 개정안을 적용하지 않는다.

## 목적과 공식 근거

기존 연말정산 환급액 계산기는 확인된 공제 인원·금액을 입력받는다. 새 페이지 `parent-deduction-calculator.html`은 국민연금을 받는 부모님 한 분의 공제 자격·소득금액을 확인하는 별도 검색 의도를 해결한다. 두 페이지를 서로 연결하고 연도별 복제 URL을 만들지 않는다.

- [소득세법 제50조](https://www.law.go.kr/법령/소득세법/제50조): 부모·배우자의 부모 등 직계존속의 나이, 생계, 소득금액 100만원 이하 / 근로소득만 있는 경우 총급여 500만원 이하, 기본공제 150만원.
- [제51조](https://www.law.go.kr/법령/소득세법/제51조): 기본공제 대상자의 경로우대(70세 이상 100만원)·장애인(200만원), 종합소득금액을 넘는 인적공제 제외.
- [제53조](https://www.law.go.kr/법령/소득세법/제53조): 생계·별거·판정시기. 사망·관계 변동·해외 부양은 이 도구에서 확정하지 않는다.
- [제47조의2](https://www.law.go.kr/법령/소득세법/제47조의2), [국세청 연금소득](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7889&mi=6453): 총연금액에서 구간별 공제, 최대 900만원. 법령 본문 접근 시 외곽 페이지만 표시되어 `lawService`의 조문 화면까지 확인했다.
- [국세청 2026년 연말정산 유의사항](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?mi=2307&nttSn=1348212): 소득 종류별 합산, 비과세·분리과세 제외, 중복 공제 방지. 이 자료의 귀속연도는 2025년이므로 새 페이지의 2026년 적용은 위 현행 조문과 별도로 대조했다.
- [국민연금 과세제도](https://www.nps.or.kr/pnsinfo/ntpsklg/getOHAF0088M0.do), [원천징수영수증 안내](https://www.nps.or.kr/elctcvlcpt/comm/getOHAC0000M5.do?menuId=MN24001061): 2002년 이후 보험료에 대응하는 과세대상 연금, 국민연금 유족·장애연금 비과세, 과세기준금액과 공제 후 소득금액의 구별. 영수증 구축 시기를 확인하지 않고 당장 조회 가능하다고 약속하지 않는다.

## 계산·표시 원칙

- 순수 계산은 `YearEndTaxMath.calculateParent`·`pensionDeduction`에 추가하고 기존 근로소득공제 함수를 재사용한다. 기존 환급액 계산 알고리즘과 입력 동작은 바꾸지 않는다.
- 과세대상 연금액 모드에서는 공제를 계산한다. 영수증 소득금액 모드에서는 재공제하지 않는다. 월 입금액·세금 0원·수령액 전체를 과세대상액으로 추정하지 않는다.
- 일반 근로소득은 비과세 제외 총급여에서 근로소득공제를 차감한다. 다른 종합소득은 확인된 필요경비 반영 후 소득금액, 퇴직은 퇴직소득공제 전, 양도는 양도소득 기본공제 전 금액을 합산한다. 음수 손익통산·특수 조정을 자동 계산하지 않는다.
- 근로소득만 있는 경우의 예외는 연금 없음/비과세만 있음 등 확인 가능한 경우에만 적용한다. 다른 소득금액이 공제 후 0원이 되는 혼합 사례에서 합계 100만원을 넘고 총급여 500만원 이하라면 예외 적용을 단정하지 않고 `review`로 둔다. 공식 근거로 세부 사실을 확정할 수 없는 범위다.
- 금액은 원 단위 정수 입력, 계산 중 소수는 보존(센트 단위 연산으로 부동소수 오차 방지). 예: 과세대상 5,166,666원은 소득금액 999,999.6원, 5,166,667원은 1,000,000.2원이다. 화면에서도 소수를 표시하여 반올림 때문에 판정과 표시가 어긋나지 않게 한다. 실제 영수증 금액 확인 경로도 제공한다.
- 소득·부양·중복 등 미확인, 다른 연금, 사망·해외·손익통산·주택담보노후연금 이자비용 공제 등은 추가 확인으로 표시한다. 모르는 금액을 0원으로 간주하지 않고 공제액을 확정하지 않는다. 필수 요건이 명백히 실패하면 입력 기준 불가이며, 별도 검토 사례는 확정 판정하지 않는다.
- 결과는 공제액이며 환급액이 아니다. 한 분의 기본공제 인원과 추가공제액을 기존 환급액 계산기에 합산하는 방법을 안내한다. 부모 두 분 소득은 합치지 않는다. 입력값은 서버로 보내거나 저장하지 않는다.

## 별도 데이터 점검 (이번 변경 범위 외)
