## 주택담보대출 이자 소득공제

공식 근거:

- [소득세법 제52조](https://www.law.go.kr/법령/소득세법/제52조): 현행 2026-01-01 시행 본문 확인.
- [소득세법 시행령 제112조](https://www.law.go.kr/법령/소득세법시행령/제112조): 현행 2026-10-01 시행 본문 확인.
- [국세청 장기주택저당차입금 이자상환액 공제 안내](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=239020&mi=40630).

지원 범위는 2015년 이후 취득·신규 차입의 일반적인 적격 금융기관 주택담보대출이다. 근로소득 있는 거주자, 적격 세대주/세대원, 연말 세대 전체 주택 수, 주택 유형, 소유자·채무자·본인 부담, 금융기관 차입·저당 설정을 각각 확인한다. 세대원은 세대주의 주택자금 공제 미적용·실제 거주 등 해당 요건을 확인하도록 설명한다.

취득 당시 기준시가 한도는 취득연도 2015~2018년 4억원, 2019~2023년 5억원, 2024년 이후 6억원이다. 현재 시가·현재 공시가격과 혼동하지 않도록 입력 도움말을 둔다. 최초 공시 전 차입은 법정 최초 공시가격 등을 별도로 확인한다.

연간 한도는 15년 이상이며 고정금리·비거치식 분할상환 둘 다 충족하면 2,000만원, 하나만 충족하면 1,800만원, 둘 다 아니면 800만원이다. 10년 이상 15년 미만이며 둘 중 하나를 충족하면 600만원이다. 은행의 상품 명칭만으로 세법상 고정금리·비거치식을 추정하지 않는다. 고정금리의 5년 단위·70% 기준, 비거치식의 거치기간·연간 원금 상환 기준을 설명하고 금융기관 증명서 확인을 유도한다.

공제 여지 = 해당 합산 한도 − 다른 주택자금 **소득공제액**. 결과는 실제 이자와 0 이상인 남은 한도 중 작은 금액이다. 다른 공제는 납입액 전체를 입력하지 않는다. 이는 소득공제액이며 환급액이 아니다. 최종 공제에는 공제받는 사람의 소득금액 범위도 적용된다.

등기일부터 3개월을 넘은 신규 차입은 미충족으로 표시한다. 3개월은 일수 90일이 아니라 달력 월 기준으로 계산하고, 대응하는 일이 없는 달은 말일로 맞춘다(1월 31일 → 4월 30일). 등기 전 차입, 취득일보다 앞선 등기일, 누락 날짜, 2015년 전 취득·차입은 추가 확인으로 남긴다. 대환·승계·공동채무·분양권·과거 경과규정 등의 별도 검토 선택 시 일반 계산으로 확정하지 않는다.

## 의료비 세액공제

공식 근거:

- [소득세법 제59조의4 제2항](https://www.law.go.kr/법령/소득세법/제59조의4).
- [소득세법 시행령 제118조의5](https://www.law.go.kr/법령/소득세법시행령/제118조의5).
- [국세청 의료비 과다공제 유의사항](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?mi=2307&nttSn=1348212): 2026년 1월 안내의 실제 부담·보험금·형제자매 사례 확인.

총급여는 비과세를 뺀 근로소득공제 전 금액이다. 네 구분 각각에서 적격 지출액 − 같은 연도·같은 구분 지출을 보전한 실손보험금·본인부담상한제 환급금·지원금 등을 계산한다. 보험금이 해당 구분의 지출액보다 크면 자료 재확인 오류를 표시한다.

총급여 3%를 일반 부양가족 → 본인 등 한도 없는 대상 → 미숙아·선천성이상아 → 난임시술비 순서로 한 번만 차감한다. 일반 부양가족은 차감 후 700만원 한도, 앞 두 구분은 15%, 미숙아·선천성이상아 20%, 난임시술비 30%를 적용한다. 6세 이하 대상은 과세기간 개시일, 65세 이상은 종료일 기준이며 세법상 장애인·산정특례 등 해당 대상 요건을 확인한다. 각 구분은 중복 입력하지 않는다.

안경·콘택트렌즈 1명당 연 50만원, 산후조리원 출산 1회당 200만원 등 개별 항목 한도는 사용자가 적격 금액을 확인한 뒤 입력한다. 사람별 안경 한도·출산 횟수 자동 판정 기능은 없다. 비급여 여부만으로 적격을 추정하지 않는다. 미용·성형·건강기능식품 등 제외 항목과 실제 부담·근로기간·가족 부양·다른 가족의 공제 여부를 설명한다.

부모님 인적공제의 나이·소득 기준과 의료비 기준을 혼동하지 않도록 별도 설명한다. 형제자매·맞벌이 사이에서 실제 부담자와 기본공제 관계를 무시하고 의료비를 임의로 옮길 수 있다고 안내하지 않는다.

요건을 확인하지 않았으면 계산 가정액과 확정하지 않은 공제액을 분리한다. 선택적으로 공제 전 남은 국세 소득세와 비교하되 기납부세액·전체 결정세액·지방소득세·표준세액공제 선택을 추정하지 않는다. 국세 계산액을 현금 환급액이라고 표시하지 않는다. 원 미만 정밀도는 중간 계산에서 유지하며 표시 반올림과 신고서 절사의 차이를 고지한다.

## 부모님 건강보험 피부양자

공식 근거:

- [국민건강보험법 시행규칙 제2조](https://www.law.go.kr/법령/국민건강보험법시행규칙/제2조): 2026-09-28 시행 기준.
- [같은 시행규칙 별표 1의2](https://www.law.go.kr/법령별표서식/(국민건강보험법시행규칙,20260928,별표1의2)): 2025-04-23 개정 별표 PDF를 현행 시행규칙과 대조.
- [별표 1의2 공식 PDF](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110201&flSeq=158657039&gubun=).
- [국민건강보험공단 피부양자 해설](https://www.nhis.or.kr/lm/lmxsrv/data/commentaryDataRoomView.do?seqJomun=0&seqJomunData=67691): 가족관계·부양·소득자료 반영 확인.

부모님 한 분을 대상으로 한다. 본인의 공단 반영 소득 합계가 연 2,000만원 이하여야 한다. 재산세 과세표준 5.4억원 이하는 일반 소득 한도, 5.4억원 초과~9억원 이하는 연 소득 1,000만원 이하, 9억원 초과는 미충족으로 표시한다. 시가나 공시가격을 재산세 과세표준으로 대입하지 않는다.

사업소득은 별도 요건을 적용한다. 등록사업·주택임대 소득이 있으면 일반적으로 미충족이다. 사업자등록 없는 일반사업(주택임대 제외), 법정 등록 장애인·상이등급 등 해당 예외는 연 사업소득금액 500만원 이하를 확인한다. 예외 확인 전은 판정을 유보한다. 세법상 장애인 의료비 대상과 이 예외 자격을 같다고 추정하지 않는다.

기혼이면 배우자도 별도로 소득·사업소득 요건을 충족해야 한다. 부부 소득을 더해 2,000만원 한 번과 비교하거나, 배우자 재산을 부모님 과표에 무조건 합산하지 않는다. 배우자 소득 합계에는 입력한 배우자 사업소득도 이미 포함되어야 한다.

소득 입력은 **국민건강보험공단 자료에 반영되는 금액**이다. 공적연금과 근로소득은 공제 전 금액을 확인하고, 소득세 부모님 인적공제의 과세대상 연금 일부·연금소득공제나 지역보험료의 50% 평가율을 적용하지 않는다. 이자·배당은 행정 자료의 반영 범위·시점을 확인하도록 하며, 적은 금융소득을 원천 수령액만 보고 임의로 0원 처리하는 분기를 만들지 않았다. 공단 적용액을 확인하지 못했으면 예상액의 한도 초과만으로 자격 탈락을 확정하지 않는다.

부모님·배우자 부모님 관계, 별표 1의 동거/별거 부양요건, 다른 가입 상태도 확인해야 한다. 소득 조정·폐업·해외·사적연금·재건축 등 개별 사례는 별도 확인으로 남긴다. 실제 공단의 자격 결정, 취득·상실일, 탈락 후 지역보험료를 계산하지 않는다.

## SEO·이미지·사용성 검토

검토일에 다음 네이버·구글 공식 안내를 확인했다.

- [네이버 콘텐츠 기본](https://searchadvisor.naver.com/guide/content-basic), [콘텐츠 마크업](https://searchadvisor.naver.com/guide/markup-content), [사이트 구조](https://searchadvisor.naver.com/guide/markup-structure).
- [Google 검색 Essentials](https://developers.google.com/search/docs/essentials?hl=ko), [유용한 콘텐츠](https://developers.google.com/search/docs/fundamentals/creating-helpful-content?hl=ko), [SEO 기본 가이드](https://developers.google.com/search/docs/fundamentals/seo-starter-guide?hl=ko).

고유 제목·H1·description·self-canonical, 일치하는 공개 URL·사이트맵·RSS, 실제 본문과 같은 breadcrumb, 정확한 WebApplication 구조화 데이터를 적용했다. 주요 설명·공식 출처·적용 연도·예제·FAQ·관련 링크는 생성 HTML에 포함한다. 검색량·순위나 공제 승인·환급액을 보장하지 않는다. 신규 FAQPage 마크업이나 허위 평점을 넣지 않았다. 홈·이용 안내·기존 부모님 공제·연말정산 페이지에서 자연스럽게 연결했다.

각 페이지의 `images/og/<페이지명>.png`는 새로 생성한 고유 512×512 PNG이다. [OG 이미지 규칙과 정확한 생성 프롬프트](../images/og/README.md)에 기록했다. 완성본의 한글·여백을 육안 검토하고 OG/Twitter 절대 URL·크기·alt를 확인했다. 리사이즈 후 PNG의 비픽셀 메타데이터를 제거하고 청크 CRC와 IDAT 보존을 확인했다. 파일 메타데이터 정리는 검색 순위 개선을 보장하는 근거로 취급하지 않는다.

기존 폼·결과 보고서·FAQ·공유·내보내기·반응형 스타일을 재사용한다. 금액·단위·기준 시점을 입력 가까이에 표시하며 조건부 배우자/세금 입력은 숨김과 disabled를 함께 변경한다. 빈 오류 문구는 처음부터 hidden이며 오류 해제 시 다시 숨긴다. 입력 변경·잘못된 입력은 이전 결과를 숨기고, 성공 결과와 오류에는 각각 초점을 이동한다. 입력은 브라우저에서 계산하며 저장하거나 서버로 전송하는 기능을 추가하지 않았다.

## 별도 데이터 페이지 사전 점검

[데이터 갱신 정책](data-update-policy.md)의 공식 출처를 읽기 전용으로 점검했다. 금감원 동적 조회·국민연금 통계·한국부동산원 통계와 일부 통계 목록은 자동 조회만으로 최신 기준 기간을 확정할 수 없었다. 가계금융복지조사 목록에서 2026 신규 발표를 확인하지 못했다. 생활업종·소득·기준중위소득 출처도 확인했으나 이 작업과 무관한 데이터는 변경하지 않았다. 이전 점검에서 기록한 건강보험 지역 통계의 후속 갱신도 별도 근거 요약·승인 대상이며, 이번 계산기 추가가 해당 페이지 수정 승인은 아니다.

## 같은 날 사용자 요청에 따른 최종 사용성 보완

- 의료비 지출과 보험금·환급금을 미리 빼서 넣는 중복 차감을 예방하도록 첫 안내와 항목별 도움말을 수정했다. 미숙아·난임 지출 도움말에서 관계없는 안경·산후조리원 예시를 제거했다. 네 보험금 입력란의 접근성 이름을 구분하고, 초과 입력 오류에는 해당 구분을 표시한다.
- 의료비와 주담대는 공제 결과를 표 맨 위에 배치하고, 미확인·미충족이면 먼저 확인할 사유를 바로 표시한다. 요건 충족 결과의 중복 가정액, 의료비 미사용 구분의 0원 상세 행, 선택하지 않은 남은 소득세 비교는 생략한다. 실제 사용한 지출의 차감 과정은 유지하며, 공제 계산액이 0원인 이유도 설명한다. 부적격 의료비가 포함된 결과는 전체 의료비의 공제 불가로 오해하지 않도록 대상 아닌 금액을 제외하고 재계산하도록 안내한다.
- 주담대의 30년·이자 0원 기본값은 실제 입력으로 오인할 수 있어 빈 필수 입력으로 변경했다. ‘등기일 기준 3개월 말일’은 세 번째 달의 무조건 말일이라는 뜻으로 읽힐 수 있으므로 ‘신규 차입 기한 · 등기일부터 3개월’로 바꿨다. 계산 수식과 날짜 규칙은 변경하지 않았다.
- 선택한 의료비 세금 비교와 배우자 소득 합계도 0원으로 임의 확정하지 않도록 빈 필수 입력으로 시작한다. 사용자가 확인한 실제 0원은 정상 입력할 수 있다. 배우자 없음으로 바꾸면 숨긴 필드가 유효성 검사를 막지 않는다.
- 건강보험 소득·재산 확인 선택을 금액·배우자 입력 다음으로 옮겼다. 월액/연간·원 단위·모르는 금액과 실제 없는 소득의 차이를 설명하고, 작은 화면의 긴 확인 선택 문구를 줄였다. 결과는 소득 초과 시 초과액을 보여주며, 소득 상한까지 남은 금액이 사업·재산·부양요건까지 보장하는 여유액이 아님을 설명한다.

Chrome 기본 화면과 320×844 에뮬레이션에서 입력 안내·줄바꿈·필수 입력·배우자 조건부 입력·확인 선택을 점검했다. 의료비 예제는 기본 화면에서 키보드 Enter 제출로 225,000원 계산을 확인하고, 같은 결과를 320px 화면에서도 확인했다. 기기 에뮬레이션의 네이티브 자동 클릭·타이핑은 일부 초점 이동이 불안정하여 실기기 터치 검증으로 간주하지 않는다. 변경한 표시·초기값·조건부 유효성 검사와 PNG/PDF/공유는 DOM 통합 검사에 회귀 항목을 추가했다. 공식 계산 기준·세율·금액 한도는 변경하지 않았고, 같은 날 완료한 데이터 페이지 읽기 점검 결과를 유지한다.
