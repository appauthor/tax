# 연말정산·국민연금·예금 순위

검토일: 2026-09-13. 각 페이지는 기존 공통 화면·결과 내보내기를 사용한다. UI는 `scripts/planning-calculators.js`, 계산은 각 `*-math.js`에 분리한다.

## 연말정산

- [국세청 근로소득공제](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=6435&cntntsId=7871), [과세표준](https://g.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7873&mi=6594), [세액공제](https://t.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7875&mi=6439), [소득세법](https://www.law.go.kr/법령/소득세법).
- 2026년 근로소득만 있는 거주자. 총급여 → 근로소득공제 → 확인된 소득공제 → 과세표준·산출세액 → 세액공제 → 결정세액 → 실제 기납부세액과 정산. 국세청의 총급여 3,380만 원 / 근로소득공제 1,032만 원 사례를 검증한다.
- 기본세율과 연금계좌 공제는 `InvestmentTaxMath`를 재사용한다. 표준공제 비교 시 특별소득공제, 특별세액공제 및 월세를 모두 제외한다. 특별공제액 합계와 13만 원을 단순 비교하지 않는다.
- 소득·세액공제의 자격, 종합한도, 중복 제한은 확인된 공제금액 입력으로 제한한다. 중소기업 취업자 등 감면, 외국납부세액, ISA 전환, 농어촌특별세, 복수 소득, 이월 및 정치자금·고향사랑·우리사주 기부금 특례는 제외한다. 지방소득세는 국세 결정세액의 10% 추정이며 국세·지방세 기납부액은 별도 입력한다. 원 단위 반올림은 표시 때만 한다.
- IRP 추가 납입 비교는 공제한도 및 산출세액 한도를 함께 반영한다. 환급액이 기납부세액을 넘거나 결정세액이 음수가 되지 않아야 한다.

## 국민연금

- [국민연금공단 지급개시 나이](https://www.nps.or.kr/pbcpgdnc/mainbiz/getOHAG0058M0.do), [급여·조기·연기 규정](https://www.nps.or.kr/pnsinfo/ntpsklg/getOHAF0110P0.do).
- 공단 정상 예상월액(세전, 부양가족연금 제외)을 입력받는다. 평균소득으로 가입이력별 급여를 임의 추정하지 않는다. 최소 가입 인정기간 120개월, 조기 소득요건 확인, 월별 0.5% 감액·0.6% 가산, 최대 60개월을 구분한다.
- 비교 나이까지 경과한 온전한 개월 수로 누적한다. 출생일·청구일·지급일 달력 계산이 아니다. 동액 또는 최초 초과 월을 손익분기점으로 올림한다. 물가·할인율·소득감액·추가가입·세금·건보·유족급여는 제외한다.

## 예금·적금 데이터 운영

- [금융감독원 정기예금](https://finlife.fss.or.kr/finlife/svings/fdrmDpst/list.do?menuNo=700002), [적금](https://finlife.fss.or.kr/finlife/svings/fdrmEnty/list.do?menuNo=700003)의 공개 HTML을 수집한다. 인증이 필요한 Open API나 다른 사람의 인증키는 사용하지 않는다.
- `npm run data:refresh-savings` 또는 `python3 tools/refresh-savings-rates.py`로 `scripts/savings-rank-data.js`를 원자적으로 갱신한다. 실행 환경에 네트워크와 Python 3이 필요하다. 이 변경은 스케줄러나 운영 배포를 활성화하지 않는다. 운영 시 매일 수집 후 테스트하고 변경된 데이터 파일을 배포하는 작업을 연결한다.
- 수집 범위: 은행·저축은행, 가입대상 제한 없음, 6·12·24개월, 예금 및 정액적립식 적금. 목록의 전체 건수와 읽은 행 수가 다르면 실패한다. 필드·금리·기간·중복 검증 실패 또는 일부 요청 실패 시 기존 스냅샷을 교체하지 않는다. `--output PATH`로 별도 후보 파일을 만들 수 있다.
- 기본금리와 최고금리를 보관하되 최고금리는 모든 조건 충족 가정이다. 우대조건 자동 판정은 하지 않는다. 금액별 구간, 최소납입액·미공시 한도 등은 공식 공시에서 확인하도록 안내한다. 값이 없는 한도를 무제한으로 단정하지 않는다. 예금 공시의 숫자 상한이 있으면 초과 입력을 필터링한다.
- 세후 이자 계산은 기존 `calculateSavingsInterest`를 재사용한다. 적금은 매월 초 동일 금액 납입, 일반과세, 만기 유지 가정이다. 조회 옵션 내림차순 상위 50행을 보여주며 원 단위 이자 동률은 공동순위이다. 동일 상품의 단리·월복리는 구별한다.
- 수집 시각과 상품 공시월은 별도 값이다. 7일 경과 시 과거 자료로 표시한다. 새 데이터가 없다고 최신 날짜로 덮어쓰지 않는다. 이용자의 입력은 브라우저 안에서만 계산한다.

## 검증

- `node tests/calculation-regression.test.js`는 `tests/planning-calculators.test.js`를 포함한다.
- `python3 tests/savings-data.test.py`는 공개 HTML 파싱, 누락·스키마 변경, 기존 파일 보존을 검증한다.
- `node tests/planning-dom.test.js /path/to/jsdom`으로 실제 HTML·공통 스크립트의 폼과 PNG/PDF/공유 경로를 검증한다. jsdom은 저장소 의존성으로 추가하지 않으며, 내보내기 라이브러리는 이 테스트에서 대역이므로 실제 Chrome 캡처로 별도 확인한다.
- `data-full-report-table` 표는 내보낼 때만 전체 높이로 펼친다. 모바일 가로 스크롤과 긴 표의 화면 높이 제한을 저장 결과에 그대로 복사하지 않는다.
