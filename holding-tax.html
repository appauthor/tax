공시가격 입력 안내

주소 검색 후 기준연도와 동·호를 선택하면 VWorld 공동주택가격 API 조회 결과가 자동으로 입력됩니다. 직접 입력도 가능합니다.

재산세는 주택 단위 공시가격, 종부세는 인별 합산 공시가격과 공제 구조를 중심으로 확인합니다.

입력값이 세액으로 바뀌는 순서

  1. 주택별 공시가격을 조회하거나 직접 입력합니다.
  2. 공동명의라면 본인 지분율만큼 재산가액을 안분합니다.
  3. 재산세는 공정시장가액비율과 주택 세율 구간을 적용합니다.
  4. 종부세는 인별 주택 공시가격 합계에서 기본공제를 차감한 뒤 계산합니다.

고령자·장기보유 공제, 공동명의 1주택 특례, 세부 도시지역분은 실제 고지서와 차이를 만들 수 있습니다.

비교 사례

단독명의와 5:5 공동명의

공시가격 12억 원 주택이라면 계산기 입력 기준 본인 지분 상당액은 단독명의 12억 원, 5:5 공동명의 6억 원입니다. 종부세는 인별 합산과 공제가 중요하므로 단순히 세액이 절반이라고 단정할 수 없습니다.

공시가격이 10% 오른 경우

과세표준과 누진 구간이 함께 변할 수 있어 고지세액도 반드시 10%만 오르는 것은 아닙니다.
